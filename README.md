## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) validates `POST.json` names a real X post address and copies it to the output directory, where the gate reads it. Fill in the real post URL in `POST.json` after publishing — the placeholder status id `0000000000000000000` is refused by the gate as it stands.
